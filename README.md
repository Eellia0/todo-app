# Todo App 📝

Современное React-приложение для управления задачами с TypeScript, красивым дизайном и полным покрытием тестами.

##  Функциональность

- ✅ Добавление новых задач
- ✅ Отметка задач как выполненных
- ✅ Удаление задач
- ✅ Фильтрация: Все/Активные/Выполненные
- ✅ Счетчик оставшихся задач
- ✅ Очистка выполненных задач
- ✅ Адаптивный дизайн
- ✅ Анимации и плавные переходы
- ✅ Полное e2e тестирование

##  Технологии

- **React 18** с хуками
- **TypeScript** для типобезопасности
- **Cypress** для e2e тестирования
- **CSS3** с кастомными анимациями
- **Google Fonts** (Outfit)

##  Установка и запуск

```bash
# Клонирование репозитория
git clone <repository-url>
cd todoapp

# Установка зависимостей
npm install

# Запуск в development режиме
npm start

# Запуск тестов Cypress
npm run cypress:open

# Сборка для production
npm run build

## Основные компоненты:
AddTodo - форма ввода новых задач

TodoItem - отображение отдельной задачи

TodoList - список задач с фильтрацией

Footer - информационная панель

Хуки:
useTodos - управление состоянием задач

## Скрипты
npm start          # Запуск development сервера
npm run build      # Сборка production версии
npm test           # Запуск unit тестов
npm run cypress:open # Интерактивные e2e тесты
npm run cypress:run  # headless e2e тесты
